# Azzup

Personal finance management API for Brazilian employees working under the CLT employment model.
See [docs/business/product-overview.md](docs/business/product-overview.md).

## Status

Structure, placeholder files, and architectural and business documentation only. No functionality is implemented.
Laravel is not installed. Infrastructure files are placeholders.

## Layout

- `src/` — future Laravel application root.
- `docker/` — planned container definitions (placeholders).
- `docs/` — architectural standards; `docs/business/` — business requirements. Start at [docs/README.md](docs/README.md).
- `bruno/` — future Bruno HTTP request collections.
- `CLAUDE.md` — documentation router for AI-assisted development.

## Planned Stack

Laravel, PHP, PostgreSQL, Docker Compose, Nginx, Sanctum, Reverb (optional), Telescope, Pulse, Pint, Queues, Scheduler, Mailpit.
See [docs/infrastructure/docker.md](docs/infrastructure/docker.md).
