# Transaction Categories

## Purpose
The fixed set of categories used by transactions and bills.

## Categories
| Category key | Meaning |
|---|---|
| `housing` | Housing |
| `food` | Food |
| `transportation` | Transportation |
| `health` | Health |
| `leisure` | Leisure |
| `education` | Education |
| `subscriptions` | Subscriptions |
| `other` | Other |

## Rules
- The list is fixed. No category management features unless explicitly requested.
- Use the English keys consistently in code, database, and API.
