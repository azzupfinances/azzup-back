# Unit Tests

## Purpose
Test isolated logic without HTTP.

## Rules
- Location: `tests/Unit/`, mirroring the `app/` structure.
- Target Services, Rules, Helpers, and Support classes with non-trivial logic.
- Avoid testing framework behavior.
- Test names and assertions in English.
