# Language

## Purpose
The project uses English exclusively.

## Rules
English is mandatory in all project content, including:
- Source code, class, method, variable, file, and directory names.
- Database tables and columns.
- API routes, parameters, and JSON responses.
- Validation messages and attributes.
- Exception and error messages.
- Enum values intended for display.
- Logs and code comments.
- Documentation and Markdown files.
- Test names and assertions.
- Configuration files.
- Commit messages and pull request descriptions.

Do not introduce Portuguese or any other language unless explicitly instructed.

## Dates and Times
No business-specific timezone or date format is assumed. Define the API standard when first needed and document it in [JSON Responses](../api/json-responses.md).
