# Code Style

## Purpose
Formatting and code quality rules.

## Rules
- Format PHP with Laravel Pint (default Laravel preset) once installed.
- Use strict types and declare parameter and return types.
- Prefer dependency injection over facades inside Services when testability matters.
- Keep methods short and focused. Avoid premature abstraction.
- Comments explain why, not what, and are written in English.
