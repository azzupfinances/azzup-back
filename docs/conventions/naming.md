# Naming Conventions

## Purpose
Authoritative naming table.

## Conventions
| Element | Convention |
|---|---|
| PHP classes | PascalCase |
| Module class directories | PascalCase |
| Methods | camelCase |
| Variables | camelCase |
| Database tables | snake_case |
| Database columns | snake_case |
| API route paths | kebab-case |
| Route files and directories | kebab-case |
| Markdown filenames | kebab-case |
| Permission keys | dot.notation |
| Configuration keys | Laravel conventions |
| Environment variables | UPPER_SNAKE_CASE |

Class suffixes: `Controller`, `Request`, `Service`, `Policy`, `Test`.
